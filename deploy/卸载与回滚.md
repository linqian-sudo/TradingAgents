# 环境说明、卸载与回滚

## 环境

- 安装位置由 `--prefix` 决定，默认是 `$HOME/.local/share/tradingagents-research`。
- Python 虚拟环境在 `$PREFIX/venv`。系统 Python 不被修改。
- 包装脚本在 `$PREFIX/bin`。它们强制 `TRADINGAGENTS_NO_UPDATE_CHECK=1`，并把结果、缓存、记忆日志默认放到 `$PREFIX/var`。
- 调用时用 `--output` 指定的目录只属于那一次命令。
- 不创建 systemd、cron 或监听端口。`docker-compose.yml` 仍在源代码里，研究安装脚本不会执行它，也不会映射公网端口。
- 不读取安装目录以外的持仓文件。研究运行固定 `portfolio=None`，并且不提供持仓参数。
- 上游包在导入时会从当前工作目录向上寻找 `.env`。请在没有私人 `.env` 的目录里启动，或只使用不含密钥的示例文件。不要把填好的环境文件提交到公开 fork。

已在云 VM 验证的解释器是 CPython 3.12.3。父级共享 Linux 需要自行运行 `deploy/install.sh`，本记录不表示那里已经安装。

## 卸载

保留缓存与一次运行的输出：

```bash
./deploy/uninstall.sh --prefix "$HOME/.local/share/tradingagents-research"
```

连同该前缀下的 `var/` 一起删除：

```bash
./deploy/uninstall.sh --prefix "$HOME/.local/share/tradingagents-research" --purge-data
```

只有在确认 `~/.tradingagents` 不是别人的目录、并且可以删除时，才追加 `--purge-home`。默认不删除它。

卸载不撤销系统包，因为安装没有使用系统 site-packages。

## 回滚

1. 先卸载当前前缀，或改用一个新的 `--prefix`，避免两个 venv 混用。
2. 用原来的 `tradingagents-research-0.7.1-9fa1196.tar.gz` 重新解压并执行 `install.sh`。版本与 commit 写在包内 `research_entry/provenance.py` 和安装后的 `VERSION_MANIFEST.json`。
3. 不要通过 `git pull` 或升级到未钉住的上游 commit 来“回滚”。本交付物就是这个 commit 的可安装包。
4. 若锁文件安装失败，保留 pip 日志。不要改用未审核的镜像或别的数据接口。需要浮动版本时必须显式传入 `--unpinned`，并知道它与已验证锁文件可能不同。
